# ADR-0004: Tiers + availability resolver, манифестите се рендерират от effective

Статус: прието (2026-10-31). Източник: `docs/design/research-fable.md` §12.

## Контекст

list endpoints не доказано филтрират по ключ ([V]); Claude Code не проверява `--model` предварително ([V]).

## Решение

probe с `max_tokens:1`, кеш, `effective = allowed ∩ available`, генерираните файлове съдържат само effective.

## Отхвърлено

доверие в list endpoint; runtime fallback по време на работа за мисловни задачи.

## Последствие

един probe на 24 h; липсващ EXPERT е нормалното състояние, не грешка.
