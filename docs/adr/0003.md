# ADR-0003: Политиката живее в repo-то, таванът извън него и извън write-set-а на агента, разхлабването само от default branch, прочетен през hosting API

Статус: прието (2026-10-31). Източник: `docs/design/research-fable.md` §12.

## Контекст

project файл не може да пази себе си ([V]); allowed команди изпълняват кода на агента; локалните git refs са записваеми.

## Решение

§3.3–3.4 със стъпка 0 (ОС sandbox като граница).

## Отхвърлено

подписан policy файл (ключ на машината на агента = подправим); само CODEOWNERS (admin bypass по подразбиране [V]); label като доказателство за одобрение (`pull-requests: write` не се дели).

## Последствие

нужен remote, ruleset и ОС sandbox за L≥2; локални проекти без remote или без sandbox остават ≤ L1.
