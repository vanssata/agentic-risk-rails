# ADR-0010: Test impact с твърд под за пълен run

Статус: прието (2026-10-31). Източник: `docs/design/research-fable.md` §12.

## Контекст

Spec фаза и suite са най-скъпите части.

## Решение

`rr affected` на стъпка, пълен run при тригер и при close, nightly, `selection_misses`.

## Отхвърлено

само affected (пропуска интеграционни счупвания).

## Последствие

„двата факта“ остават с пълен run при close.
