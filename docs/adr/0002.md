# ADR-0002: Go статичен бинар

Статус: прието (2026-10-31). Източник: `docs/design/research-fable.md` §12.

## Контекст

hook на всеки tool call, 7 runtime-а, разпространение през npm/brew.

## Решение

Go + `mvdan/sh` + `go-sdk`.

## Отхвърлено

Bun compile (50–90 MB [V]), Rust (итерация, `rmcp` [U]), Python (старт, интерпретатор).

## Последствие

пренаписване от нулата; екипът трябва да е добър в Go.
