# ADR-0009: Shell guard по AST, fail-closed, под ОС sandbox

Статус: прието (2026-10-31). Източник: `docs/design/research-fable.md` §12.

## Контекст

regex е „tripwire“; и AST guard е tripwire, защото allowed команди изпълняват кода на агента.

## Решение

`mvdan/sh`, неразпознат възел ⇒ ask (L0/L1) / deny (L≥2), `unlisted: ask`/deny, `fail_closed: true` навсякъде, hook timeout кратък с `onFailure: block`; protected и secret paths се налагат от `enforcement.sandbox`, компилиран към runtime-а.

## Отхвърлено

regex като основа (остава втори слой); hook като единствена граница.

## Последствие

по-често `ask` при екзотични команди; L≥2 изисква sandbox.
