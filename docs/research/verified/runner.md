## PROXY MECHANISM (choice)
A Squid container (any image the operator pins by digest, `--pull never`) with a generated `squid.conf` mounted read-only: `acl` of the allowed domains, `http_access allow CONNECT SSL_ports allowed`, `http_access deny all`. Why Squid: dstdomain ACL + CONNECT tunnelling is its core use, no TLS interception (no CA in the agent), config is one file generated by rr. The image and its entrypoint are an operator input; rr runs `squid -N -f /etc/squid/squid.conf` with `--entrypoint squid`. Not run against a real image in this wave [U] (needs RR_CONTRACT=1 and an image).
